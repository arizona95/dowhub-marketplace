# 원천 트리 한 항목 조사 (aar_menu)

리뷰를 전수로 돌려도 트리엔 **보고서가 안 붙은 항목**이 남는다. 이 스킬은 그 빈칸 하나를 메운다.

## 0) 인자 — `/aar_menu <트리> <노드경로>`
```
/aar_menu menu claude-app/개인설정/Desktop app/Developer
```
- **트리** = `menu` · `session` · `settings` · `retention` 중 하나.
- **노드경로** = 루트부터 `/` 로 이은 경로. 뷰어의 복사 버튼이 그대로 넣어준다.
- 인자가 없거나 불완전하면 **되묻지 말고** `tree("list")` → `tree("get", …)` 로 후보를 보여주고
  어느 항목인지 한 번만 확인한다.

## 1) 그 노드가 이미 아는 것부터 읽는다 (중복 조사 금지)
`tree("get", <트리>)` 로 트리를 받아 그 경로의 노드를 찾는다. 노드엔 보통 이미 들어 있다:
- `desc` — 지금까지 파악된 설명 · `key` — 설정 키 · `gate` — 토글 상태(on/off)
- `has_report` — **이미 보고서가 붙어 있으면 그렇다고 말하고 멈춰라.** 중복 작성 금지.

## 2) 화면으로 확인한다 (여기가 본체)
내 브라우저로 그 제품의 그 화면을 **직접 열어** 항목을 찾는다. 캡처는 그 항목이 **화면에 보이게**
찍어 `/api/v1/evidence` 로 올린다(절차는 `skill("get", "aar_review/refs/capture-and-workflow.md")`).

무엇을 볼지 — 네 가지를 채운다:
1. **기능** — 이 항목이 무엇을 하나. 켜면/끄면 무엇이 달라지나.
2. **설정 방법과 현재값** — 어디서 바꾸나, 지금 기본값은 무엇인가.
3. **보안 권고** — 어떤 값이어야 하나, **왜** 그런가.
4. **위험** — 잘못 두면 무엇이 가능해지나(구체적 시나리오로. "위험함" 같은 말은 금지).

보고서에 없는 걸 물으면 **공식문서**를 찾아 URL 과 함께 댄다. 둘 다에 없으면 **"확인 불가"** 로
남긴다 — 추측을 사실처럼 쓰지 마라. 판정 기호는 `O / X / - / ?` 만.

## 3) 보고서를 쓰고 **그 노드에 붙인다**
```
html_report(session, scenario="menu-<노드슬러그>", title=…, summary=…,
            blocks=[{"type":"shot", "label":…, "caption":…, "items":["<그 노드 id tnd_…>"]}, …])
```
- 🚨 **블록에 `items`(그 노드의 id — `tree("get")` 결과의 id)를 빼면 트리에 안 붙는다** — 빈칸이 그대로 남는다. 옛 `tag={"tree","path"}` 경로 입력도 아직 받지만 새로 쓸 땐 `items`.
- 조사하며 알게 된 것은 **먼저 항목에 남긴다**(`update_tree` 설명·`shot_set` 사진 세트·`checklist_set` 판정) — 보고서는 그 요약이다.
- 완료도(leaf 사진)는 **유효 증적**으로만 센다: 그 블록에 실제 캡처가 있거나 그 노드에 사진 세트가 붙어야 "사진 있음". 항목 연결만으로는 0.
- `title` = 이 리포트가 **하려는 일**(검토 목적·범위). 결과·결론은 `summary` 와 본문에.
- 캡처 없는 주장은 넣지 마라. 캡처 0장이면 그건 보고서가 아니다.

## 4) 트리도 갱신한다 (알게 된 걸 남긴다)
조사하며 새로 안 것(설명이 비었거나 틀렸거나, 하위 항목을 더 봤거나, 토글 상태가 달라졌으면)은
`update_tree(tree_id, node_path=[…], patch=[…])` 로 그 앵커에만 반영한다. **본 것만** 넣는다.

## 절대 규칙
- **제품 무관** — 어떤 SaaS 든 이 스킬로 조사한다. 특정 벤더 값을 정답처럼 박지 마라.
- **한 항목만** — 옆 항목까지 번지지 마라. 여러 개면 각각 `/aar_menu` 로 부른다.
- **이미 보고서가 있으면 멈춘다** — 갱신이 필요하면 `/aar_update` 가 델타로 한다.
- 화면을 못 열거나 로그인이 필요하면 우회·추측 말고 **사용자에게 알리고 멈춘다**.
